# قالب اولیه سایت یارک (Yarak Services)

این پروژه یک **نمونه نمایشی فرانت‌اند** فارسی و واکنش‌گرا است که برای انتشار رایگان در GitHub Pages آماده شده است.

## فایل‌ها
- `index.html` — تمام HTML/CSS/JavaScript نسخه اولیه
- `assets/yarak-hero.jpg` — تصویر پس‌زمینه اصلی (باید تصویر خودتان را در این مسیر قرار دهید)
- `assets/yarak-logo.png` — لوگوی یارک (باید تصویر خودتان را در این مسیر قرار دهید)

## انتشار در GitHub Pages با گوشی
1. وارد https://github.com شوید و حساب بسازید یا وارد شوید.
2. روی `+` بزنید و `New repository` را انتخاب کنید.
3. نام مخزن را `yarak-services` بگذارید و `Public` را انتخاب کنید. سپس `Create repository`.
4. وارد مخزن شوید، `Add file` → `Upload files` را بزنید.
5. فایل `index.html` و فایل `README.md` را از این پوشه آپلود کنید. پوشه `assets` را هم بسازید و دو تصویر را در آن آپلود کنید:
   - `assets/yarak-hero.jpg` تصویر اول، عکس واقعی موتورسوار در شهر
   - `assets/yarak-logo.png` تصویر دوم، لوگوی انیمیشنی
   نام فایل‌ها باید دقیقاً مطابق همین نام‌ها باشد.
6. پس از آپلود، در مخزن به `Settings` → `Pages` بروید.
7. در `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
8. Branch را روی `main` و پوشه را روی `/(root)` بگذارید و `Save` بزنید.
9. یک تا چند دقیقه صبر کنید. آدرس معمولاً این شکل است:
   `https://YOUR-USERNAME.github.io/yarak-services/`
   به جای `YOUR-USERNAME` نام کاربری GitHub خودتان قرار می‌گیرد.

## چه چیزهایی در این نسخه واقعی نیست؟
- سفارش‌ها فقط در حافظه همان نشست مرورگر نمونه‌سازی می‌شوند؛ به دیتابیس ارسال نمی‌شوند.
- فرم استخدام رزومه را به شرکت ایمیل نمی‌کند و اطلاعات استخدام ذخیره نمی‌شود.
- پنل مدیریت امن ساخته نشده است؛ فعلاً فقط یادداشت فاز بعدی دارد.
- چت‌بات پاسخ‌های نمایشی دارد و به مدل هوش مصنوعی متصل نیست.
- پرداخت آنلاین، ارسال پیامک و اعزام واقعی وجود ندارد.
- فایل‌های رزومه و عکس نباید در مخزن عمومی GitHub آپلود شوند.

برای نسخه عملیاتی باید بک‌اند امن و دیتابیس (مثلاً Supabase) اضافه شود؛ ورود مدیر، دسترسی خصوصی فایل‌ها و سیاست‌های امنیتی دیتابیس باید سمت سرور تنظیم و آزمایش شوند.

## نکته تصاویر
این بسته تصاویر اصلی را شامل نمی‌شود. عکس‌ها را خودتان داخل `assets` قرار دهید. برای عکس اصلی از `yarak-hero.jpg` و برای لوگو از `yarak-logo.png` استفاده کنید.
